# RailMate 智轨伴行 · 项目一页纸（给老师快速扫版）

> **一句话吹满**：这不是「套壳大模型」，而是一套**面向铁路出行的对话式决策引擎**——自然语言理解意图，**工具编排**查票/中转，**结构化卡片**承载真相，**SSE 实时进度**拒绝黑盒；演示闭环里连**电子检票都是真实 HTTP 链路**（扫码即改后端状态），工程上把合规边界和产品体验同时讲圆。

---

## 我们到底做了什么？

| 标签 | 说明 |
|------|------|
| **定位** | 铁路场景 **AI Copilot**：说人话 → 自动规划 → 可点的结果，而不是一篇作文。 |
| **交互** | 对话 + **快捷回复** + 语音；查票页独立 GUI；**车次类型仅前端筛选**，后端一次拉全量——职责清晰，可扩展。 |
| **智能** | Agent **工具调用**（直达/中转检索），提示词约束「少查无效日期、多吐卡片」；规划过程 **SSE 推送**，用户看得见「查到哪一步」。 |
| **闭环** | 演示模式本地落单 → **行程管理** → **二维码 = 后端检票 URL**，访问即检票成功页（含乘车人等）→ 列表实时同步「已检票」；**已检票不出退票**，规则像真系统。 |
| **工程** | Next.js + FastAPI；React Query 轮询/失效；持久化与 **hydration** 门控等——**能答辩、能演示、能迭代**。 |
